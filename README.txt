MOZA LEGAL — نسخة مرتبطة بـ Supabase

الملفات:
- index.html: الموقع العام ونموذج إرسال الاستشارة.
- admin.html: لوحة دخول المحامي ومتابعة الطلبات.
- admin_permissions.sql: سياسة تسمح للمدير بتحديث حالة الطلب.

الإعداد:
1) افتح Supabase > SQL Editor.
2) شغّل محتوى admin_permissions.sql مرة واحدة.
3) ارفع index.html و admin.html إلى نفس مجلد الاستضافة.
4) افتح index.html للزوار.
5) افتح admin.html للمحامي وسجّل الدخول ببريد وكلمة مرور مستخدم Authentication الذي أضفته.
6) يجب أن يكون user_id لهذا الحساب موجودًا في public.legal_admins (وقد تحققنا من أن admin_count = 1).

ملاحظات أمنية:
- المفتاح الموجود في ملفات HTML هو Publishable Key فقط، وهو مصمم للاستخدام في المتصفح.
- لا تضع service_role أو Secret Key في أي ملف واجهة.
- الوصول إلى بيانات العملاء محمي بسياسات RLS، ويجب أن يبقى مفعّلًا.
- لا تنشر بيانات دخول المحامي.
- هذه النسخة تحفظ طلبات الاستشارة في Supabase ولا ترسلها تلقائيًا عبر واتساب.
